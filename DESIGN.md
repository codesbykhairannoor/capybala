# Capybala Design System (DESIGN.md)

## 1. Identity & Purpose
- **Product**: Capybala — Zero-dependency mathematical agent deadlock detection, circuit breaking & self-healing library.
- **Audience**: Systems engineers, LLM agent researchers, autonomous coding framework developers (SWE-bench, LangGraph, CrewAI, AutoGen, Llama Stack).
- **Voice & Mood**: Mathematical, austere, utilitarian, high-signal, calm. No AI marketing fluff, no fabricated trust badges.
- **Inspiration**: SQLite docs, Vercel developer interfaces, Linear engineering specs.

## 2. Palette & Contrast
- **Base Surfaces**:
  - Ground Plane: `#0a0c10` (deep matte obsidian)
  - Secondary Surface / Panels: `#12161f` (neutral slate)
  - Card / Field Surface: `#171c26`
  - Subtle Borders: `#232a38`
- **Text & Hierarchy**:
  - Primary Headers / High Contrast: `#f8fafc` (APCA compliant Lc > 90)
  - Body Text: `#cbd5e1` (contrast ratio > 7:1)
  - Muted Metadata / Code Syntax: `#818cf8` / `#94a3b8`
- **One Deliberate Accent**:
  - Warm Amber (`#f59e0b`, hover `#d97706`) — Capybala's signature warmth, representing alert and watchful guardrails.
- **Functional Semantics**:
  - Deadlock Intercepted / Alert: `#f43f5e` (rose coral)
  - Healthy Progression / Clean: `#10b981` (emerald)
  - State Metric / Velocity: `#38bdf8` (sky blue)

## 3. Typography
- **UI Sans**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Mono / Math**: `"JetBrains Mono", "SF Mono", ui-monospace, Menlo, Consolas, monospace`

## 4. Antislop Dials
- **ENERGY**: 2 (Focused developer utility with interactive simulator)
- **RHYTHM**: 2 (Clear visual hierarchy: playground hero, live metric readout, copy-ready integration, reproducible benchmarks)
- **MOTION**: 1 (Immediate functional state updates, 150ms hover transitions, zero floating decorative orbs)

## 5. Non-Negotiable Bans (Anti-Slop Hard Gates)
- NO generic blue-purple gradient backgrounds or radial mesh orbs.
- NO decorative capsule badges with pulsing green dots.
- NO fake statistics, fake logos, or fake testimonials.
- NO dummy buttons or non-functional mock UI — every interactive element runs actual Python Capybala algorithms.
