# Capybala Design System (DESIGN.md)

## 1. Identity & Purpose
- **Product**: Capybala — Zero-dependency mathematical agent deadlock detection, circuit breaking & self-healing library.
- **Audience**: Systems engineers, LLM agent researchers, autonomous coding framework developers (SWE-bench, LangGraph, CrewAI, AutoGen, Llama Stack).
- **Voice & Mood**: Mathematical, austere, utilitarian, high-signal, calm. No AI marketing fluff, no fabricated trust badges.
- **Theme**: Light Mode by default (warm editorial paper & slate), with high-contrast accessibility and toggle support.

## 2. Palette & Contrast (Light Mode Default)
- **Base Surfaces (Light)**:
  - Ground Plane: `#f8fafc` (crisp slate-50)
  - Secondary Surface / Panels: `#ffffff` (pure white card)
  - Field / Code Surfaces: `#f1f5f9` (soft slate-100)
  - Crisp Borders: `#e2e8f0` (slate-200) / `#cbd5e1` (slate-300)
- **Text & Hierarchy (Light)**:
  - Primary Headers / High Contrast: `#0f172a` (slate-900, APCA compliant Lc > 95, contrast > 15:1)
  - Body Text: `#334155` (slate-700, contrast > 9:1)
  - Muted Metadata / Subtitles: `#64748b` (slate-500)
- **One Deliberate Accent**:
  - Warm Honey Amber (`#d97706` / hover `#b45309`) — Capybala's signature warmth, representing alert and watchful guardrails.
- **Functional Semantics**:
  - Deadlock Intercepted / Alert: `#e11d48` (rose-600) with light background `#ffe4e6` (rose-100)
  - Healthy Progression / Clean: `#059669` (emerald-600) with light background `#d1fae5` (emerald-100)
  - State Metric / Velocity: `#0284c7` (sky-600) with light background `#e0f2fe` (sky-100)

## 3. Typography
- **UI Sans**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Mono / Math**: `"JetBrains Mono", "SF Mono", ui-monospace, Menlo, Consolas, monospace`

## 4. Antislop Dials
- **ENERGY**: 2 (Focused developer utility with interactive simulator & vector manifold visualizer)
- **RHYTHM**: 3 (Dynamic, rich section pacing: live playground, vector bucket projector, architecture comparison, empirical SWE-bench benchmarks, and integration hub)
- **MOTION**: 1 (Immediate functional state updates, 150ms hover transitions, zero floating decorative orbs)


## 5. Non-Negotiable Bans (Anti-Slop Hard Gates)
- NO generic blue-purple gradient backgrounds or radial mesh orbs.
- NO decorative capsule badges with pulsing green dots.
- NO fake statistics, fake logos, or fake testimonials.
- NO dummy buttons or non-functional mock UI — every interactive element runs actual Python Capybala algorithms.
