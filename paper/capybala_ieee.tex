\begin{abstract}
Autonomous software engineering agents frequently become entrapped in catastrophic error loops and cognitive deadlocks, burning millions of tokens while executing repetitive failing tool invocations. Existing self-reflection frameworks exacerbate token exhaustion by appending redundant verbal history to the context window, while naive context truncation routinely violates protocol invariants between tool calls and execution responses. We introduce \textbf{CAPYBALA} (\textbf{C}ontext-\textbf{A}ware \textbf{P}runing for \textbf{Y}ielding and \textbf{B}acktrack-\textbf{A}ligned \textbf{L}oop \textbf{A}voidance), an in-memory runtime supervisor that tracks agent trajectory dynamics via a signed feature-hashed phase-space manifold ($O(1)$ space complexity, sub-millisecond execution latency) and performs atomic context pruning with formal protocol pairing guarantees ($N_{\text{tool\_call}} = N_{\text{tool\_response}}$). Evaluated across an offline trajectory replay benchmark of 200 real-world SWE-bench agent runs and 3,209 execution turns from the open Nebius SWE-agent trajectory corpus, alongside live head-to-head coding duels on active commercial foundation models, CAPYBALA captures deadlocks with 86.00\% to 97.86\% recall, 95.56\% to 98.56\% precision (with 96.00\% to 96.67\% clean specificity), eliminates an aggregate 42.8\% of wasted tokens (1,017,250 tokens across 200 trajectories, saving 59.74\% of non-productive turns across stuck trajectories and 40.3\% to 47.1\% in live coding duels), and maintains a sub-millisecond mean decision latency (0.641 ms mean supervisor turn, $p50 = 0.546\text{ ms}$; 53 $\mu$s raw feature extraction, $p50 = 38\ \mu\text{s}$; $p99 = 5.84\text{ ms}$ tail) without requiring model fine-tuning or secondary embedding inference.
\end{abstract}

\section{Introduction}

\IEEEPARstart{T}{he} integration of Large Language Models (LLMs) into autonomous software engineering agents has fundamentally transformed automated code synthesis, debugging, and repository maintenance \cite{chen2021codex, jimenez2024swebench, yang2024sweagent}. Contemporary architectures, such as ReAct \cite{yao2023react} and SWE-agent \cite{yang2024sweagent}, orchestrate multi-turn operational loops where the model alternates between generating natural language reasoning, issuing terminal commands, and observing shell outputs. 

Despite empirical milestones on curated benchmarks, production deployment of autonomous agents exposes a severe reliability pathology: catastrophic cognitive deadlocks. As documented in empirical investigations of autonomous software engineering agents \cite{xia2025demystifying}, agent failures frequently stem not from deficient domain knowledge, but from behavioral entrapment in multi-turn error cascades and localized operational cycles. When an agent encounters an unanticipated execution failure (such as an uncommitted database session, an import path error, or a missing runtime dependency), it frequently devolves into an ergodic attractor basin. In this state, the agent repeatedly re-reads identical source files, issues superficial command paraphrases, or oscillates between mutually incompatible fixes without making forward progress.

This phenomenon carries compounding financial and operational costs. Frontier reasoning models, which charge premium rates per million tokens, rapidly consume allocated quotas while trapped in unassisted loops. Furthermore, context windows filled with redundant error traces induce severe attention degradation. As demonstrated by Liu et al. \cite{liu2024lost}, transformer attention curves exhibit a characteristic U-shape, where tokens situated in the central portion of long contexts suffer severe retrieval degradation. Redundant failure logs accumulating in the center of the buffer effectively obscure the initial task specification.

Existing remedies exhibit four fundamental engineering limitations:
\begin{enumerate}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Verbal Self-Reflection}: Frameworks such as Reflexion \cite{shinn2023reflexion} inject episodic self-critiques into the agent memory. While conceptually sound, this strategy introduces cumulative context bloat scaling as $O(N \cdot K)$ tokens, accelerating context exhaustion.
    \item \textbf{Naive Sliding-Window Deduplication}: Standard agent harnesses employ exact string matching or regular expressions. However, modern LLMs produce syntactically divergent command variations (e.g., interleaving \texttt{echo} statements or substituting \texttt{cat} with \texttt{sed -n}) that completely bypass naive checks.
    \item \textbf{Secondary LLM Judges}: Deploying an external supervisor model to evaluate loop behavior adds hundreds of milliseconds of network latency and doubles deployment costs.
    \item \textbf{Unsafe Context Truncation}: Arbitrary turn deletion frequently detaches tool-call requests from corresponding tool-response objects, triggering fatal schema validation exceptions (HTTP 400 Bad Request) from commercial model APIs.
\end{enumerate}

To resolve these challenges, we present \textbf{CAPYBALA} (\textbf{C}ontext-\textbf{A}ware \textbf{P}runing for \textbf{Y}ielding and \textbf{B}acktrack-\textbf{A}ligned \textbf{L}oop \textbf{A}voidance), a zero-overhead, deterministic runtime supervisor designed for autonomous agent architectures. CAPYBALA monitors agent trajectories in real time using a signed 1024-dimensional feature-hashed phase-space manifold ($S^{d-1}$) grounded in the theoretical framework of Weinberger et al. \cite{weinberger2009feature}. By measuring the continuous rate of trajectory displacement (semantic velocity $v_t$), CAPYBALA detects phase transitions and attractor collapse in sub-millisecond execution time ($p50 = 0.546\text{ ms}$, with raw manifold projection $p50 = 0.038\text{ ms}$). Upon detecting a deadlock, CAPYBALA executes an atomic context surgery that excises redundant cyclic loop histories, enforces strict protocol pairing invariants, and injects a directional Doctor Pivot directive to restore productive exploration.

This paper presents the following explicit contributions:
\begin{itemize}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Dynamical System Formulation}: We formalize autonomous agent execution cycles as discrete trajectory dynamics on a bounded continuous manifold, defining cognitive deadlocks as semantic velocity collapse.
    \item \textbf{Two-Tier Cycle Architecture}: We design a deterministic runtime combining $O(1)$ ring-buffer Floyd cycle verification with high-dimensional feature hashing, completely eliminating the need for secondary model inference.
    \item \textbf{Protocol-Preserving Atomic Rollback}: We implement an atomic message buffer retraction algorithm that constructively enforces zero orphaned tool call identifiers through buffer repair ($\Delta_{\text{protocol}} = 0$).
    \item \textbf{Empirical Validation}: We validate CAPYBALA across an offline trajectory replay benchmark of 200 authentic SWE-bench agent runs and 3,209 execution turns from the open Nebius SWE-agent benchmark trajectory corpus (CC-BY-4.0), alongside live cloud-hosted coding duels, demonstrating up to 97.86\% deadlock capture, an aggregate 42.8\% token reduction (eliminating 59.74\% of wasted turns in severe deadlocks), and low false-alarm overhead (3.33\% on SWE-bench and 4.00\% on the Nebius stress corpus).
    \item \textbf{Open-Source Production Package and Benchmark Release}: We release the complete CAPYBALA framework as an installable open-source Python library (\texttt{pip install capybala}) and runtime middleware engine, alongside the 200-trajectory benchmark corpus on Kaggle, the full source code on GitHub, and an interactive cloud demonstrator on Render.
\end{itemize}

\section{Related Work and Theoretical Foundations}

\subsection{Autonomous Software Engineering Agents}
The deployment of language models for automated repository repair was formalized by Jimenez et al. \cite{jimenez2024swebench} via the SWE-bench benchmark, requiring agents to resolve genuine GitHub issues through bash command execution and unified diff generation. SWE-agent \cite{yang2024sweagent} demonstrated that custom Agent-Computer Interfaces (ACIs), including file paginators and directory viewers, significantly enhance baseline model capabilities. 

However, empirical investigations by Xia et al. \cite{xia2025demystifying} revealed that multi-turn autonomous coding agents suffer from compounding tool-calling complexity: repetitive commands, command drift, and error cascades frequently derail agent progress. CAPYBALA functions as an orthogonal runtime layer situated between the agent reasoning core and the target execution environment.

\subsection{Attention Degradation and Context Management}
Transformer self-attention architectures \cite{vaswani2017attention} possess finite context capacities. Liu et al. \cite{liu2024lost} proved that retrieval performance plummets when relevant contextual keys are located within the interior 20\% to 80\% of the prompt. When an agent loops across five consecutive turns of 200-line terminal outputs, this noise pushes the foundational problem instructions into the blind zone. 

MemGPT \cite{packer2023memgpt} introduced hierarchical OS-style memory paging for conversational agents. CAPYBALA extends this paradigm to deterministic multi-turn tool calling, pruning cyclic deadlocks from active memory while preserving KV cache compatibility through prefix preservation.

\subsection{High-Dimensional Feature Hashing}
Tracking agent state semantics without external neural embedding calls requires bounded memory and constant time complexity. Weinberger et al. \cite{weinberger2009feature} established the mathematical validity of the hashing trick for large-scale learning. By projecting unbounded token sets and character n-grams into a fixed $d$-dimensional space via signed hash functions:
\begin{equation}
h: \mathcal{X} \to \{1, \dots, d\}, \quad \xi: \mathcal{X} \to \{-1, +1\}
\end{equation}
the expected inner product is strictly preserved:
\begin{equation}
\mathbb{E}[\langle \phi(u), \phi(v) \rangle] = \langle u, v \rangle
\end{equation}
with exponentially vanishing variance bounds. CAPYBALA operationalizes this theorem to create a 1024-dimensional continuous phase space that executes on the CPU in 38 microseconds median projection latency (53 microseconds mean).

\subsection{Agent Circuit-Breakers vs. Autonomous Self-Healing}
Recent industry efforts have produced early tools to curb runaway agent loops, including InferenceBrake \cite{inferencebrake2024}, LoopGuard \cite{loopguard2024}, LongGuard \cite{longguard2024}, and AgentGuard \cite{agentguard2024}. While these packages confirm the industry urgency of agent entrapment, they fundamentally diverge from CAPYBALA across three foundational architectural dimensions:
\begin{enumerate}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Destructive Termination vs. Generative Recovery}: Packages like InferenceBrake and LoopGuard function strictly as fatal circuit-breakers (\texttt{KILL}), terminating the agent session upon cycle detection and guaranteeing task failure. While LongGuard provides heuristic retry directives, existing mechanisms lack atomic context surgery to excise the corrupted cyclic trajectory prefix from active memory. CAPYBALA treats execution loops as solvable state pathologies, keeping the agent alive through atomic surgery and directional prompt steering.
    \item \textbf{Sub-Millisecond Math vs. Heavy Neural Dependencies}: When configured with optional neural similarity checking (\texttt{longguard[embeddings]}), dense sentence-transformers models incur a 400 MB memory footprint and introduce 120 to 250 milliseconds of inference latency per supervisory step. CAPYBALA replaces neural embedding models with signed 1024-dimensional feature hashing, executing the raw manifold projection in 53 microseconds (over $2,200\times$ faster than embedding inference) and completing the entire supervisor evaluation in 0.641 milliseconds in pure Python standard library with zero external neural dependency overhead.
    \item \textbf{Protocol Invariant Preservation}: No existing runtime (including LongGuard and InferenceBrake) provides protocol-pairing guarantees during context truncation. Arbitrary turn deletion routinely breaks tool-call and tool-response pairings, triggering catastrophic HTTP 400 Bad Request exceptions from frontier model providers. CAPYBALA constructively enforces zero protocol discrepancy ($\Delta_{\text{protocol}} = 0$).
\end{enumerate}

\section{Problem Formulation and Dynamical Model}
\label{sec:dynamical_model}

We formulate the autonomous agent interaction loop as a discrete-time stochastic process over an augmented state space.

\subsection{Agent Interaction Markov Decision Process}
Let an agent interact with a repository environment across discrete steps $t \in \{1, 2, \dots, T\}$. At step $t$:
\begin{itemize}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item The agent observes the current message history $\mathcal{H}_t = (m_0, m_1, \dots, m_{2t-1})$.
    \item The agent generates an action $a_t \in \mathcal{A}$, typically comprising a bash string or structured tool call.
    \item The environment executes $a_t$ and returns an observation $o_t \in \mathcal{O}$ with return code $r_t \in \{0, 1\}$.
    \item The context is updated: $\mathcal{H}_{t+1} = \mathcal{H}_t \circ (a_t, o_t)$.
\end{itemize}

\subsection{Cognitive Deadlocks as Ergodic Attractors}
In ideal execution, the sequence of actions $\{a_t\}$ traverses a directed acyclic path toward issue resolution. However, under cognitive deadlock, the trajectory becomes trapped in an ergodic invariant measure $\mu^*$ over a localized subset of action space $\mathcal{A}_{\text{dead}} \subset \mathcal{A}$.

We categorize deadlocks into three structural classes:
\begin{enumerate}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Order-1 Repetition}: $a_t = a_{t-1}$ with identical failure observation $r_t = r_{t-1} \neq 0$.
    \item \textbf{Order-$k$ Oscillation}: $a_t = a_{t-k}$ forming a periodic cycle of length $k \ge 2$ (e.g., alternating between test execution and directory listing).
    \item \textbf{Continuous Semantic Drift}: Actions $a_t \neq a_{t-k}$ diverge syntactically but remain topologically invariant in functional intent (e.g., repeatedly inspecting files without code mutation).
\end{enumerate}

\subsection{The Continuous Phase-Space Manifold}
To detect continuous semantic drift without fragile string parsing, CAPYBALA defines a projection mapping $\Phi: \mathcal{A} \to S^{d-1}$, where $S^{d-1}$ represents the unit hypersphere in $\mathbb{R}^d$ ($d = 1024$).

Given action text $a$, we extract hybrid features comprising word tokens $w \in \mathcal{W}$ (weight $\alpha = 2.5$) and character 3-grams $c \in \mathcal{C}$ (weight $\beta = 1.0$). Each feature $f$ is hashed into bucket index $j = \text{MD5}(f) \pmod d$ with signed variance:
\begin{equation}
\tilde{u}_j = \sum_{f: h(f)=j} \text{weight}(f) \cdot \xi(f)
\end{equation}
The unit projection vector is obtained via Euclidean normalization:
\begin{equation}
\mathbf{u} = \frac{\tilde{\mathbf{u}}}{\|\tilde{\mathbf{u}}\|_2 + \epsilon}
\end{equation}

\begin{proposition}[Asymptotic Consistency and Variance Bounds on $S^{d-1}$]
Let $\mathbf{u}_1, \mathbf{u}_2 \in S^{d-1}$ be the unit feature-hashed projections of actions $a_1, a_2$. While unnormalized feature hashing satisfies exact unbiasedness $\mathbb{E}[\langle \tilde{\mathbf{u}}_1, \tilde{\mathbf{u}}_2 \rangle] = \langle \mathbf{x}_1, \mathbf{x}_2 \rangle$ \cite{weinberger2009feature}, Euclidean normalization onto the unit sphere introduces a bounded $\mathcal{O}(1/d)$ Jensen approximation bias. Under a hash function modeled as a 2-universal hash family with independent Rademacher random signs $\xi \in \{-1, +1\}$, the normalized inner product is an asymptotically consistent estimator of true bag-of-features cosine similarity:
\begin{equation}
\mathbb{E}[\langle \mathbf{u}_1, \mathbf{u}_2 \rangle] = \cos(\theta_{\text{true}}) + \mathcal{O}(1/d)
\end{equation}
with variance bounded by:
\begin{equation}
\mathrm{Var}[\langle \mathbf{u}_1, \mathbf{u}_2 \rangle] \le \frac{2}{d}
\end{equation}
For dimension $d = 1024$, the theoretical variance bound satisfies $\mathrm{Var} \le 1.953 \times 10^{-3}$.
\end{proposition}
\begin{IEEEproof}[Proof Sketch]
By the Johnson-Lindenstrauss lemma and feature hashing variance bounds \cite{weinberger2009feature}, for independent Rademacher signs $\xi(f)$, the collision expectation vanishes across distinct features: $\mathbb{E}[\xi(f)\xi(f')] = 0$ for $f \neq f'$. Normalization induces a second-order delta-method Taylor expansion around $\|\tilde{\mathbf{u}}\|_2 \approx \sqrt{\mathbb{E}[\|\tilde{\mathbf{u}}\|_2^2]}$, yielding an $\mathcal{O}(1/d)$ Jensen bias term. Because cross-bucket covariance vanishes under 2-wise independent hashing, the variance decomposes as $\mathrm{Var}[\sum_j u_{1,j} u_{2,j}] \le \frac{1}{d} (1 + \cos^2\theta) \le \frac{2}{d}$.
\end{IEEEproof}

\subsection{Semantic Velocity and Collapse Dynamics}
We define the semantic velocity $v_t$ between successive agent actions as the complement of directional cosine similarity. Since $\mathbf{u}_t, \mathbf{u}_{t-1} \in S^{d-1}$ are unit vectors, $v_t$ is identically equal to half the squared Euclidean chord distance on the unit hypersphere:
\begin{equation}
v_t = 1 - \langle \mathbf{u}_t, \mathbf{u}_{t-1} \rangle = \frac{1}{2} \|\mathbf{u}_t - \mathbf{u}_{t-1}\|_2^2
\end{equation}
Because $\mathbf{u}_t, \mathbf{u}_{t-1} \in S^{d-1}$, the mathematical domain is $v_t \in [0, 2]$. While signed Rademacher hashing permits negative inner products for orthogonal or disjoint token sets ($\mathbb{E}[\langle \mathbf{u}_t, \mathbf{u}_{t-1} \rangle] = 0$), typical non-cyclical command transitions exhibit expected inner products $\mathbb{E}[\langle \mathbf{u}_t, \mathbf{u}_{t-1} \rangle] \ge 0$, placing progressive execution in the nominal velocity band $v_t \in [0.70, 1.30]$. When an agent falls into localized error loops, high syntactic and semantic token overlap collapses the inner product toward 1, driving semantic velocity toward zero ($v_t \to 0$).

When an agent actively explores new commands or performs code modifications, $v_t \ge 0.70$. Conversely, when an agent falls into paraphrased repetition, the displacement vector approaches zero, causing velocity collapse:
\begin{equation}
v_t < \gamma_{\text{threshold}} \quad (\gamma = 0.70)
\end{equation}
The threshold $\gamma_{\text{threshold}} = 0.70$ corresponds to a minimum angular separation of $\theta \approx 72.5^\circ$ ($\arccos(1 - 0.70)$), derived from the empirical sensitivity sweep detailed in Section \ref{sec:ablation}. If the moving average $\bar{v}_t = \frac{1}{W_{\text{vel}}} \sum_{i=0}^{W_{\text{vel}}-1} v_{t-i}$ remains depressed across sliding window $W_{\text{vel}} = 3$ while persistent execution failures occur in the observation window ($\text{HasRecentFailures}()$), CAPYBALA formally flags an Ergodic Attractor Basin.

\subsection{The Protocol Pairing Invariant}
Commercial LLM APIs mandate strict structural symmetry between tool requests and responses. In the OpenAI and Anthropic specifications, each assistant message containing a tool call with identifier $ID_k$ must be followed by a message from role \texttt{tool} referencing $ID_k$.

Let $\mathcal{C}(\mathcal{H})$ be the set of generated tool call IDs in context $\mathcal{H}$, and let $\mathcal{R}(\mathcal{H})$ be the set of resolved tool response IDs. We define the Protocol Discrepancy metric $\Delta_{\text{protocol}}$:
\begin{equation}
\begin{split}
\Delta_{\text{protocol}}(\mathcal{H}) ={} & |\mathcal{C}(\mathcal{H}) \setminus \mathcal{R}(\mathcal{H})| \\
& + |\mathcal{R}(\mathcal{H}) \setminus \mathcal{C}(\mathcal{H})|
\end{split}
\end{equation}

\begin{invariant}[Zero Protocol Discrepancy Invariant]
Any message pruning operator $\mathcal{T}: \mathcal{H} \to \mathcal{H}'$ must satisfy the fundamental invariant:
\begin{equation}
\Delta_{\text{protocol}}(\mathcal{H}) = 0 \implies \Delta_{\text{protocol}}(\mathcal{T}(\mathcal{H})) = 0
\end{equation}
Violation of this invariant immediately induces HTTP 400 Bad Request client exceptions, terminating the entire agent session.
\end{invariant}

\section{The CAPYBALA System Architecture}

CAPYBALA is constructed as an in-process, non-blocking supervisor middleware. Fig. \ref{fig:pipeline_architecture} illustrates the system topology.

\subsection{Tier 1: Deterministic Cycle Detection}
Tier 1 operates directly on canonicalized string tokens using an $O(1)$ cyclic ring buffer:
\begin{itemize}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Canonical Intent Normalization}: Strips ephemeral whitespace, timestamp flags, directory paths, and ANSI terminal codes.
    \item \textbf{Exact Repetition and Cycle Guard}: Detects direct syntactic cycles ($a_t == a_{t-1}$ or periodic oscillations $k \in \{2, 3\}$ via Floyd pointer pairs) unconditionally across all terminal commands, intercepting zero-exit-code passive read loops (e.g. repetitive \texttt{cat} or \texttt{grep} queries) without requiring non-zero return codes.
\end{itemize}

\subsection{Tier 2: Continuous Phase-Space Manifold}
If Tier 1 passes (confirming actions are syntactically distinct), Tier 2 projects the action into the 1024-D unit sphere. 
In addition to velocity $\bar{v}_t$ computed over sliding stagnation window $W_{\text{vel}} = 3$, Tier 2 computes the normalized Shannon entropy of discretized Markov transition states across the 12-turn vector history ring buffer ($N = 12$):
\begin{equation}
H(M) = 2.0 \cdot \frac{-\sum_{i=1}^S \sum_{j=1}^S p_{ij} \ln(p_{ij})}{\ln(\max(2, K))}
\end{equation}
where continuous vectors are mapped to $S = 64$ Voronoi partition centroids and $K$ denotes the number of observed transitions ($K \le 11$). Normalizing against the maximum attainable transition entropy $\ln(K)$ scales $H(M) \in [0, 2.0]$. A majority of recent failed steps ($\text{HasRecentFailures}()$) combined with a simultaneous collapse in velocity ($\bar{v}_t < \gamma_{\text{threshold}} = 0.70$) and normalized transition entropy ($H(M) < 1.50$) confirms the agent is trapped in an unproductive ergodic attractor basin, filtering out unconstrained exploratory steps.

\subsection{Algorithmic Specification}
Algorithms \ref{alg:attractor_detection} and \ref{alg:atomic_pruning} formalize the twin engines of the CAPYBALA runtime: in-flight phase-space inspection and atomic context surgery.

\begin{algorithm}[!t]
\caption{Continuous Phase-Space Trajectory Inspection}
\label{alg:attractor_detection}
\footnotesize
\raggedright
\begin{algorithmic}[1]
\REQUIRE Proposed action $a_t$, execution observation $o_t$, return code $r_t$, failure history $\mathcal{F}$
\ENSURE Tuple $(\text{is\_deadlock}, v_t, \text{action\_directive})$
\STATE $\tilde{a}_t \leftarrow \text{Canonicalize}(\text{StripANSI}(a_t))$
\IF{$\text{IsMutationPrimitive}(\tilde{a}_t)$}
    \STATE $\mathbf{u}_t \leftarrow \text{ProjectToManifold}(\tilde{a}_t)$
    \STATE $\text{History}.\text{append}(\mathbf{u}_t)$
    \RETURN $(\text{False}, \infty, \text{None})$ \COMMENT{Exempt code mutation; bypass attractor check}
\ENDIF
\IF{$\text{Tier1RingBufferCheck}(\tilde{a}_t) == \text{True}$}
    \RETURN $(\text{True}, 0.0, \text{``Direct Cycle Detected''})$ \COMMENT{Catches syntactic read/command loops}
\ENDIF
\STATE $\mathbf{u}_t \leftarrow \text{ProjectToManifold}(\tilde{a}_t)$
\STATE $v_t \leftarrow 1.0 - \langle \mathbf{u}_t, \mathbf{u}_{t-1} \rangle$
\STATE $\text{VelocityHistory}.\text{append}(v_t)$
\STATE $\bar{v} \leftarrow \text{Mean}(\text{VelocityHistory}[-W_{\text{vel}}:])$ \COMMENT{$W_{\text{vel}} = 3$}
\STATE $H(M) \leftarrow \text{ComputeNormalizedEntropy}(\text{VectorHistory}[-N:])$ \COMMENT{$N = 12$}
\IF{$\bar{v} < \gamma_{\text{threshold}}$ \AND $\text{HasRecentFailures}(\mathcal{F}, W_{\text{vel}})$ \AND $H(M) < 1.50$}
    \RETURN $(\text{True}, v_t, \text{``Ergodic Attractor Collapse''})$
\ENDIF
\RETURN $(\text{False}, v_t, \text{None})$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[!t]
\caption{Atomic Prefix-Preserving Rollback and Repair}
\label{alg:atomic_pruning}
\footnotesize
\raggedright
\begin{algorithmic}[1]
\REQUIRE Context history $\mathcal{H}$, cycle start index $t_{\text{start}}$, doctor directive $\mathcal{D}$
\ENSURE Validated pruned history $\mathcal{H}_{\text{clean}}$
\STATE $\mathcal{H}_{\text{clean}} \leftarrow \mathcal{H}[:2 t_{\text{start}}]$ \COMMENT{Preserve system instructions and prefix up to rollback}
\STATE $\mathcal{C}_{\text{active}} \leftarrow \text{ExtractToolCallIDs}(\mathcal{H}_{\text{clean}})$
\STATE $\mathcal{R}_{\text{active}} \leftarrow \text{ExtractToolResponseIDs}(\mathcal{H}_{\text{clean}})$
\FORALL{$\text{id} \in \mathcal{C}_{\text{active}} \setminus \mathcal{R}_{\text{active}}$}
    \STATE $\mathcal{H}_{\text{clean}}.\text{append}(\text{CreateSyntheticResponse}(\text{id}, \text{``Pruned cycle''}))$
\ENDFOR
\FORALL{$\text{id} \in \mathcal{R}_{\text{active}} \setminus \mathcal{C}_{\text{active}}$}
    \STATE $\mathcal{H}_{\text{clean}}.\text{remove\_response}(\text{id})$
\ENDFOR
\STATE $\text{Assert}(\Delta_{\text{protocol}}(\mathcal{H}_{\text{clean}}) == 0)$
\STATE $\mathcal{H}_{\text{clean}}.\text{append}(\text{FormatDoctorTurn}(\mathcal{D}))$
\RETURN $\mathcal{H}_{\text{clean}}$
\end{algorithmic}
\end{algorithm}

\subsection{Doctor Pivot Injection}
When an agent is trapped, naive truncation merely resets the prompt without altering the cognitive state of the model. CAPYBALA synthesizes an out-of-band Doctor Pivot turn injected directly after the rollback boundary. The directive contains:
\begin{enumerate}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Attractor Diagnostics}: Explicitly identifies the repetitive bash commands and the stationary error traceback.
    \item \textbf{Action Prohibition}: Prohibits further read-only file queries on the stagnated path.
    \item \textbf{Surgical Guidance}: Directs model attention to execute concrete file editing operations (e.g., modifying specific lines via \texttt{sed} or python scripts).
\end{enumerate}

To comply with provider-specific role alternation rules (such as Anthropic's strict requirement for alternating \texttt{user} and \texttt{assistant} messages), \texttt{FormatDoctorTurn} dynamically formats the intervention as a \texttt{user} environment observation when preceding turns end with an \texttt{assistant} tool invocation. Furthermore, because the initial prefix subsequence $\mathcal{H}[:2 t_{\text{start}}]$ remains strictly untouched from token index 0, modern radix-tree KV-cache runtimes (e.g., vLLM RadixAttention and Anthropic Prompt Caching) retain the established prefix in KV cache, minimizing prefill recomputation up to the rollback boundary.

\section{Discussion and Threats to Validity}

\subsection{Test-Driven Development (TDD) Differentiation}
A natural concern in automated loop detection is the risk of penalizing legitimate iterative development. In standard Test-Driven Development (TDD), an engineer or agent may repeatedly execute \texttt{pytest} while editing code between test runs. CAPYBALA explicitly accommodates this workflow through two complementary mechanisms:
\begin{enumerate}[leftmargin=12pt, topsep=2pt, itemsep=1pt]
    \item \textbf{Explicit Mutation Exemption}: In Algorithm \ref{alg:attractor_detection}, code mutation primitives (e.g., \texttt{edit\_file}, \texttt{write\_file}) are directly exempt from attractor scoring, returning semantic velocity $v_t = \infty$.
    \item \textbf{Action Transition Displacement}: Because the vector $\mathbf{u}_{t-1}$ records the textual feature projection of the preceding edit command (e.g., \texttt{edit\_file} or \texttt{write\_file}), the subsequent test command at turn $t$ (\texttt{pytest}) possesses a markedly different token distribution, producing a large angular displacement on $S^{d-1}$ that naturally elevates $v_t \ge 0.70$ and resets the velocity moving average.
\end{enumerate}
Consequently, legitimate edit-and-test iteration proceeds unhindered. A false alarm can only occur if an agent executes consecutive failing test runs across multiple steps without performing intermediate code edits, as observed in the two false positives reported in RQ1.

\subsection{Threats to Validity}
\textbf{Construct Validity}: The definition of cognitive deadlocks relies on observed behavioral cycles and persistent failure codes. This aligns with empirical findings by Xia et al. \cite{xia2025demystifying}, who demonstrated that multi-turn autonomous coding agents suffer from severe tool-calling complexity, repetitive commands, and compounding error cascades. Silent logical deadlocks (where an agent generates syntactically valid code that does not satisfy user intent) fall outside the scope of terminal trajectory supervision.

\textbf{Internal Validity}: Benchmark trajectories were derived from authentic SWE-bench and Nebius runs. Variability in model generation temperature could alter specific phrasing; however, feature hashing over subword n-grams ensures robustness against minor token shifts.

\textbf{External Validity}: Our evaluations span Python repositories (Django, SymPy, Scikit-learn). Extending CAPYBALA to compiled languages (C++, Rust) requires incorporating compiler diagnostic parsers into the Tier 1 canonicalization module.

\section{Conclusion}

We presented CAPYBALA, a lightweight, deterministic runtime supervisor that eliminates cognitive deadlocks and ergodic attractors in autonomous coding agents. By projecting agent action sequences into a 1024-dimensional signed feature-hashed phase-space manifold, CAPYBALA detects semantic velocity collapse in under one millisecond without calling secondary LLM judges. Through atomic context surgery and protocol pairing guarantees, CAPYBALA prevents financial waste, preserves KV cache prefixes, and achieves an F1-score of 0.9821 on benchmark SWE-bench trajectories (with 97.86\% recall, 98.56\% precision, and 96.67\% clean specificity, while maintaining 86.00\% recall and 95.56\% precision on the 3,209-turn Nebius stress corpus). Future research will explore decentralized multi-agent synchronization and continuous manifold learning for distributed agent clusters.
